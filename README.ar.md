# Golan Chess Pro

[English](README.md)


تطبيق شطرنج وتدريب وتحليل بالعربية والإنجليزية. الإصدار **1.11.0 (16)**، والمعرّف `com.ibngolan.chess.pro`.

## التنزيل والتثبيت

نزّل APK وأرشيف المصدر الكامل من [الإصدارات](https://github.com/dark9guna/golan-chess-pro/releases)، ثم فك ضغط المصدر قبل البناء. Full وLite بديلان للتطبيق نفسه؛ ثبّت أحدهما. الملفان الحاليان بناءا **Debug** موجودان مسبقًا، نُسخا دون تعديل أو إعادة بناء. الحد الأدنى Android 7 / API 24. يضم Full شبكة Stockfish 19 الأكبر، بينما يوفر Lite المساحة بقوة أقل. احفظ نسخة احتياطية قبل التحديث؛ تحديث تطبيق مثبت يحتاج شهادة توقيع مطابقة.

```powershell
adb install -r Golan-Chess-Pro-1.11.0-Full.apk
# أو استخدم Golan-Chess-Pro-1.11.0-Lite.apk
```

## الوظائف

- لعب ضد المحرك ولعب محلي وتحديات مباشرة وصراع محركات وبطولات، مع ساعات وزيادة Fischer واستعادة المباراة.
- Stockfish 19 Full وLite ومحرك توافق 16، والتحقق من قانونية النقلات والترقية ونقلة مسبقة وأسهم وتلوين الرقعة.
- استيراد وتصدير PGN ومحرر FEN وأرشيف محلي ومراجعة بمنحنى تقييم وإعادة محاولة الأخطاء ودفتر تدريب.
- 49 خط افتتاح مرجعي و1,101 لغز محلي وتدريب يومي وعاصفة ألغاز ونسخ احتياطي، مع السمات والأصوات والكلام عند دعم الجهاز.

## البناء من أرشيف المصدر

يلزم Node.js متوافق مع اعتماديات Vite/Capacitor المقفلة، وnpm وJDK 21 وAndroid SDK API 36. يلزم اتصال لاستعادة الاعتماديات. ابدأ من المجلد المستخرج الذي يحتوي `package.json`.

```powershell
npm ci
npm run dev
$env:GOLAN_ENGINE_PACKAGE = 'full'
npm run build
npx cap sync android
Set-Location android
.\gradlew.bat assembleDebug
```

لبناء Lite كرر من جذر المصدر مع `GOLAN_ENGINE_PACKAGE='lite'`، وبعد المزامنة استخدم `.\gradlew.bat :app:clean :app:assembleDebug`. اضبط مسار SDK محليًا. مفاتيح التوقيع وإعدادات الجهاز غير مرفقة؛ توقيعك المحلي قد لا يتيح تحديث APK المرفق. استخدم إعدادات توقيع خاصة بك للإنتاج. بقيت الاختبارات الأصلية في المصدر، لكن لم يُنفذ بناء أو اختبار وظيفي جديد أثناء تجهيز حزمة النشر.

## الحدود والتراخيص

قوة المحرك ودقة المراجعة تقديرات، وليستا تصنيف Elo رسميًا. خدمات الاتصال والألغاز الإضافية والكلام والنهايات تعتمد على الشبكة أو الجهاز. لا يوجد خادم حسابات أو تصنيف عالمي أو مطابقة لاعبين أو مكافحة غش. الافتتاحيات للتعليم وليست إحصاءات عالمية، والأداء يعتمد على الجهاز وWebView.
